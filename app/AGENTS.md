# Web 工作区规则

本文件补充根 [AGENTS.md](../AGENTS.md)，适用于 `app/`。

- 修改前核对 PRD 对应交互与当前组件；保留已确认的导航顺序、视觉、面板、翻转卡和图操作。真实数据接入不得借机重构布局。
- `app/page.tsx` 是工作台入口；`app/software-map/` 是图、联动和源码详情；`app/lib/contracts.ts` 是服务契约镜像。模型、图数据或报告来自 fixture 时明确标示，不能描述为真实分析结果。
- 页面不新增分析算法；逐步以适配层消费 daemon 产物。原型已有演示计算不视为新架构授权，也不要求无关任务立即重构它。
- 不混用 `software-map/model.ts` 的原型结构与 `app/lib/contracts.ts` 的服务结构；明确适配，保持候选、未知、截断、错误与证据定位。
- 节点切换、重复点击、取消和慢响应不得让旧结果串到新节点。模型失败不遮挡基础事实；候选关系不能进入确定性路径。加载、空、失败、未生成各有状态。
- 代码/注释/模型文本按不可信内容渲染；避免原始 HTML 注入，禁止执行内容中的命令。代码预览保留文件、行号、Evidence ID 与截断提示。
- 修改后在 Docker 运行 tsc；UI 行为另用浏览器核验。布局变化覆盖 390/768/1136/1440px、键盘焦点及内容可达性；不是只用隐藏 overflow 消除溢出。遵守根规则关于现有测试入口的限制。
